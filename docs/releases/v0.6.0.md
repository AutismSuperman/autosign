# AutoSign v0.6.0

发布日期：2026-10-21

## 本次变更

### 全新应用图标

- 重绘了三平台主图标：蓝紫渐变圆角方块 + 环形箭头 + 对勾，边缘由矢量源按各尺寸直接渲染，不再是大图缩小的糊边。
- Windows 任务栏 / 托盘按 DPI 提供 16 / 20 / 24 / 32 像素四档图标，小尺寸只保留加粗对勾，100%–200% 缩放下都清晰；安装包图标补全 16–256 全尺寸档。
- macOS 菜单栏改用 22pt 单色模板图，并同时提供 @1x 与 @2x 两档，Retina 屏不再发虚；图标随亮 / 暗菜单栏自动反色。
- 应用内侧边栏品牌标同步换成满幅版新图标。

### 界面整体重设计

- 配色改为中性石墨灰三层底（暗色 `#1a1a1e` 底 / `#232327` 卡片 / `#2d2d33` 嵌套；亮色浅灰底 / 白卡片），阴影带 0.5px 发丝描边，暗色下轮廓更干净。
- 圆角统一为控件 7px / 卡片 12px / 对话框 14px 三档；字号统一为 11–24px 角色化层级，正文 13px，清除此前的半像素字号。
- 设置页重排为「组标题 + 连体设置行」：每行左侧 32px 图标、中间标题与说明、右侧控件；勾选框改为 30×18 的滑动开关。
- 分段选择器（主题、日志级别、登录方式等）改为带滑动滑块的新样式，切换时滑块平滑移动。
- 对话框圆角加大、入场带弹簧动画、背景毛玻璃；下拉菜单、Toast、标签胶囊等同步精细化。
- 侧栏选中项改为中性高亮（卡片底 + 发丝描边），不再使用蓝色底纹。
- 切换亮 / 暗主题时全部颜色瞬时切换，不再逐块渐变闪烁。

### 自绘标题栏

- 移除原生标题栏：窗口最上沿为自绘标题条，左上角品牌行单行显示应用名与当前版本号，中间区域可拖动窗口。
- 后台发现新版本时，版本号旁显示蓝色 `new` 徽标（此前仅弹一次通知）。
- 最小化 / 最大化 / 关闭仍为系统原生按钮（Windows 窗口控制覆叠、macOS 红绿灯），配色跟随主题；Linux 保留原生标题栏。

## 需要你手动做的

- 无需修改任何设置，覆盖安装即生效。
- Windows 用户若安装后任务栏 / 桌面仍显示旧图标，是系统图标缓存未刷新：重启资源管理器或重启电脑一次即可。

## 已知问题

- macOS 的应用内「一键重启安装」仍不可用，需要 Apple 开发者证书签名才能启用；更新方式是「收到通知 → 下载安装包 → 覆盖安装」。
- Linux 版本不使用自绘标题栏（该系统不支持隐藏原生标题栏），其余界面改动一致。
