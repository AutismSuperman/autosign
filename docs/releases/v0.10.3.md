# AutoSign v0.10.3

发布日期：2026-11-16

v0.10.2 在发布前的 Linux 验证中被拦截，未公开发布安装包；本版本继续包含以下授权修复。

## 本次变更

- 修复已经认证成功、但随后额度查询失败时，账号仍被反复要求重新授权的问题；额度暂时不可读不再被当成登录失败。
- 阻止后台和隐藏授权窗口自动弹出系统通行密钥确认；在前台授权窗口主动点击后，仍可正常使用通行密钥。
- 修复手动重新登录与后台请求同时执行时，旧请求可能覆盖新授权状态的问题。
- 修复会话已更新后，较晚返回的旧请求仍触发重复续期的问题，避免再次消费已轮换的会话。
- 已认证成功的账号会退出待恢复队列；没有待恢复账号后，后台恢复检查回到正常间隔。

## 需要你手动做的

- 覆盖安装或使用应用内更新，现有账号、凭据、签到记录和定时设置均保留，无需删除账号再添加。
- 已成功认证的账号升级后先刷新额度，无需因为旧的重新授权提示再做一次认证。
- 如果旧版仍反复弹窗，先从托盘退出 AutoSign，再安装或启动新版；仅关闭主窗口可能仍让旧版在后台运行。
- 真正失效的会话仍需要重新登录；遇到设备确认或人机验证时，请在前台授权窗口按站点提示完成。

## 已知问题

- 本版本不会跳过 GitHub 的通行密钥、两步验证、设备确认或人机验证。
- 回归测试使用模拟站点和虚拟通行密钥，未逐一验证所有真实账号及验证方式。
- macOS 的应用内更新安装仍受签名条件限制，需要时使用设置页提供的安装包下载入口。
