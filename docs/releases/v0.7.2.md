# AutoSign v0.7.2

发布日期：2026-10-22

## 本次变更

### 修回 v0.7.1 弄丢的签到金额

v0.7.1 把「余额增量」判定为不可展示，本意是修掉 +$20.90 / +$21.71 那批错数字，
但旧回执里存的全是增量，结果大批账号只剩「已签」、金额一片空白 —— 修得过头了。

现在金额会自己回来，不需要你重新签到：

- 启动后约 8 秒，对「今天已签、但金额不可信」的账号自动向站点补查一次；
- 查到就把站点记录里的真实奖励（如 +$25.00）写回回执，金额立刻恢复显示；
- 查不到就保持空白，并在悬停提示里说明「站点未回传本次签到金额」，
  而不是让你对着一个「已签」猜是不是坏了；
- 同一条回执 6 小时内最多查一次，不会每次刷新都白打请求。

### 「重登领取 / 签到」按钮重新可点

v0.7.1 的「今日已签就跳过」把手动点击也拦住了。重登类站点（AgentRouter 等）
本来就靠「登出再重登」领取，被拦住等于按钮彻底失效。

现在按发起方区分：

- **手动点行内「签到 / 重登领取」**：即使今天已经签过也真的执行一次。
  重登类站点直接重登；其它站点仍先跟站点核对，避免白撞一次人机验证。
- **「全部签到」与定时任务**：今天签过的照旧跳过，省请求、不重复撞验证。

如果重登后确实没有新的到账（多数是今天已经领过），现在会去站点记录确认一次：
确认到就如实报「已重登，今日额度此前已发放」，不再把一次成功的重登显示成红色错误。

### 批量跳过的账号会写进运行日志

以前批量签到把已签账号跳过时不留任何记录，界面上只有一句「成功 N / 总数」，
核对时看不出每个账号到底是签了还是跳过。现在每个被跳过的账号都会记一条
「今日已签到，已跳过」。

## 需要你手动做的

- 覆盖安装即可，站点、账号与凭据都会保留，不需要重新授权，也不需要重新签到。
- 安装后等约 8 秒（或点一次「刷新额度」），缺失的签到金额会自动补回。
- 若某个账号补查后仍没有金额，说明站点那边确实没有记录金额，悬停提示会写明。

## 已知问题

- 补查需要访问站点。若该站点当前被风控或网络不通，金额会保持空白，
  下次启动或刷新时会再试（每条回执 6 小时内只查一次）。
- macOS 的应用内「一键重启安装」仍不可用，需要 Apple 开发者证书签名才能启用；
  更新方式是「收到通知 → 下载安装包 → 覆盖安装」。
