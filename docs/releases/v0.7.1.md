# AutoSign v0.7.1

发布日期：2026-10-22

## 本次变更

### 设置页常驻显示项目地址与下载地址

原来的问题是：只有在检查更新失败、或 macOS 无法应用内安装时，界面才出现一个
「手动下载」按钮。这个按钮点不动（系统没有默认浏览器、链接被安全软件拦下）时，
界面上就没有任何可以抄下来的信息，等于「下载不了也不知道去哪下」。

现在「设置 → 版本与更新」里固定有两行地址，不依赖更新检查结果，任何时候都在：

- **项目地址**：`https://github.com/AutismSuperman/autosign`
- **下载地址**：`https://github.com/AutismSuperman/autosign/releases/latest`

每行提供三种取用方式，任意一种失效都还有下一种：

1. 地址用等宽字体完整显示、允许换行，可以手动选中后复制；
2. 点地址本身即复制，右侧另有明确的「复制」按钮，复制成功后按钮变成对勾；
3. 再右侧是「在浏览器中打开」，用系统默认浏览器打开。

更新失败时的状态行也直接写出可复制的下载地址，不再只有一个按钮。

### Windows / Linux 更新失败也有下载入口

此前只有 macOS 更新失败会给出手动下载入口，Windows / Linux 失败时只有一句错误。
但 Windows 的自动更新同样可能因为权限、杀毒软件或网络而失败，这时需要能自己去下载。
现在任何平台失败都会给出下载页与可复制地址。

### 未检查更新时不再是一片空白

「检查更新」那一行以前在尚未检查时什么都不显示。现在会说明
「尚未检查；启动 30 秒后会自动检查一次」，避免误以为功能坏了。

## 需要你手动做的

- 覆盖安装即可，站点、账号与凭据都会保留，不需要重新授权。
- 若你已经装了 v0.7.0，且只想拿到这次新增的地址显示，也可以不升级：
  直接访问上面的下载地址即可下载到最新正式版。

## 已知问题

- 项目地址与下载地址显示的是当前仓库与最新正式版页面。若访问 GitHub 本身不通，
  需要先在设置页「网络代理」里配置代理再打开。
- macOS 的应用内「一键重启安装」仍不可用，需要 Apple 开发者证书签名才能启用；
  更新方式是「收到通知 → 下载安装包 → 覆盖安装」。
