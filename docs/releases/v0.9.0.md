# AutoSign v0.9.0

发布日期：2026-11-10

## 本次变更

- 修复 GitHub 会话过期后，后台重授权失败、手动重新授权却能成功的问题。后台与手动授权共用状态获取、回调兑换和两步验证处理；同一次授权码只兑换一次。
- 修复令牌续期被旧结果卡住，后续会话过期时无法重新续期的问题。
- 定时签到失败后，仅重试未成功的账号，依次等待 5、10、20 分钟，当天最多自动尝试 4 次。明确需要人工验证、密码错误或站点会话数达到上限时停止该账号当天的自动重试。
- 重试次数和等待进度会保留到应用重启后；已确认签到成功的账号跳过。单个账号抛出异常不会中断其他账号。
- 定时开关、时间和工作日选项保存后立即生效。启动、休眠唤醒、解锁或恢复联网时，会检查当天是否错过设定时间，并补签符合条件的账号。离线等待不消耗重试次数。
- 同一账号的签到请求合并执行，避免手动签到、定时签到和后台会话恢复互相干扰。站点已确认今日签到时会补存回执。
- AnyRouter 定时领取会等到北京时间 08:00 的领取窗口开启，避免提前耗尽重试次数。OAuth 请求增加超时，避免站点无响应时长时间阻塞后续账号。

## 需要你手动做的

- 覆盖安装或使用应用内更新，保留现有站点、账号、凭据和定时设置。
- 需要自动签到时，请在设置中开启定时签到，并让应用在托盘中运行。时间按电脑本地时区执行。
- 已保存且仍有效的第三方登录态会自动复用；若 GitHub 或 Linux DO 要求人工验证、登录态已失效且没有可用凭据，仍需在应用内完成一次重新授权。

## 已知问题

- 应用彻底退出、电脑关机或休眠期间无法执行。恢复运行后只补当天符合工作日设置、且已到设定时间的任务，不追补历史日期。
- 网络恢复后通常在一分钟内重新检查；站点故障、限流或人工验证可能使当天签到仍未完成。重试用尽后可查看运行日志并手动签到。
- 自动重试前会核对已知签到状态，但站点必须正确返回签到结果或记录，客户端无法保证第三方接口绝对只执行一次。
- macOS 应用内自动安装仍受签名条件限制，可下载安装包后覆盖安装。
