# AutoSign v0.8.1

发布日期：2026-11-03

## 本次变更

### 收起的站点不再出现在「全部站点」里

v0.8.0 把「隐藏站点」改成侧栏逐站收起时，留了一个没想清楚的地方：
收起后侧栏不显示了，但**主视图仍然把它画出来**。结果是收起几乎没效果 ——
你想眼不见为净，还得在一排卡片里划过去。

现在按字面意思改掉：

- 收起 = 主视图也不显示。侧栏和主视图保持一致，收起就是真的看不见它；
- 想找回时，点顶栏的 **「已收起 N」** 按钮，主视图才把它们并进来；
- 再点一次就收起。这个按钮只在确实有收起站点时才出现，平时不占位置；
- 它是**临时的查看开关**，不改任何配置 —— 刷新或重启后回到默认的「不显示」。

### 全部收起时会直接给出恢复入口

如果所有站点都收起了，主视图不会只剩一句「还没有可见的站点」让你以为数据丢了。
现在会明确显示「站点都已收起」，并给一个「显示已收起（N）」按钮，
点一下就能看到全部站点。

### 顺带修正的文案

- 空状态文案不再提「在全部站点里恢复」，改为说明收起入口在侧栏站点行上；
- 侧栏顶部提示改为「点『全部站点』可查看并恢复」，与实际路径一致。

## 需要你手动做的

- 覆盖安装即可。站点、账号、凭据、签到记录全部保留，不需要重新授权。
- 如果你在 v0.8.0 里收起过站点，升级后它们会从「全部站点」里消失。
  点顶栏「已收起 N」就能看到并恢复，不会丢数据。

## 已知问题

- 「已收起 N」是临时查看状态，不记住选择。每次启动都回到「不显示」——
  这是有意的：收起本来就代表不想看见，如果记住「显示已收起」，
  下次启动又会冒出来，等于没收起。
- 同一站点批量签到仍有约 8 秒间隔（v0.8.0 引入，用于避开 Cloudflare
  频率限制），不是卡住。
- macOS 的应用内「一键重启安装」仍不可用，需要 Apple 开发者证书签名才能启用；
  更新方式是「收到通知 → 下载安装包 → 覆盖安装」。
