# AutoSign v0.5.0

发布日期：2026-10-20

## 本次变更

### 发现新版本时会主动通知

以前后台检查到新版本，只会在设置页更新一行状态，不主动提醒，
容易一直停留在旧版本。

现在后台检查到新版本会弹一次系统通知，点通知直接打开安装包下载页。
同一个版本只提示一次：这次不想更新的话，之后不会再反复打扰；
设置页里仍然随时可以看到并处理。

### macOS：检查到新版本后引导下载安装包

macOS 的应用内安装由系统更新框架负责，它只接受 ZIP 包，而且要求
安装包用 Apple 开发者证书签名才能跨版本通过校验。当前发布没有该证书，
所以 macOS 上改为：

- 检查到新版本 → 提示「发现新版本」；
- 点「下载安装包」→ 打开与你电脑架构（Apple 芯片 / Intel）对应的 DMG 直链；
- 下载后覆盖安装即可，账号、站点与登录状态都会保留。

Windows 与 Linux 不受影响，仍然自动下载、退出时安装。

### 更新失败的提示更具体

以前失败时直接显示底层报错原文。现在按原因翻译成一句可操作的话，
并在 macOS 上始终附带「手动下载」按钮，不会出现只能干等的情况。

### 里程碑里会带上本次更新内容

发布说明改为必须随版本提交，缺失会直接让发布流程失败，
不再出现「发布了但不知道改了什么」的版本。

## 需要你手动做的

- **macOS 用户请到 Release 页下载 v0.5.0 的 DMG 覆盖安装一次**。
  装好之后，今后检查到新版本会主动通知，并直接给出对应架构的下载链接。
- Windows / Linux 覆盖安装即可，不需要重新配置。
- 升级后首次检查更新会直接提示一次当前最新版本，属正常现象。

## 已知问题

- macOS 的应用内「一键重启安装」仍不可用，需要 Apple 开发者证书签名才能启用。
  在此之前，macOS 的更新方式是「收到通知 → 下载 DMG → 覆盖安装」。
- 首次打开从网上下载的 macOS 安装包时，若系统提示来源不明，
  需在「系统设置 → 隐私与安全性」里允许一次。
- 通知是否显示取决于系统的通知权限；被系统静音时，设置页仍会显示新版本状态。
