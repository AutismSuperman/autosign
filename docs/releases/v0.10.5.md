# AutoSign v0.10.5

发布日期：2026-11-23

## 本次变更

- “全部签到”和托盘的“立即签到全部”不再处理隐藏站点下的账号，签到进度也不再计入这些账号。
- 临时展开“已收起”查看隐藏站点时，它们仍不会参与批量签到；只有重新显示站点后才会重新加入。
- 批量签到进行期间隐藏站点后，该站点尚未开始的账号会跳过，已经发出的请求会正常收尾。
- 所有站点都已隐藏时，批量签到不会发起请求，托盘的批量签到入口会禁用。

## 需要你手动做的

- 覆盖安装或使用应用内更新，现有账号、凭据、签到记录和定时设置均保留，无需重新配置。
- 希望某个隐藏站点重新参与批量或定时签到时，请从“已收起”列表中重新显示该站点；仅展开查看不会恢复签到。
- 如果旧版仍在后台运行，先从托盘退出 AutoSign，再安装或启动新版。

## 已知问题

- 隐藏站点仍允许你主动点击单个账号的签到按钮；隐藏不会取消已经发出的请求。
- 回归测试使用本地模拟站点，不保证真实站点在网络故障或要求人工验证时签到成功。
- macOS 的应用内更新安装仍受签名条件限制，需要时使用设置页提供的安装包下载入口。
