# AutoSign v0.10.4

发布日期：2026-11-16

## 本次变更

- 隐藏站点后暂停该站点的自动签到、后台会话续期和自动重新授权，账号与历史数据仍保留；排队等待期间被隐藏的任务也会跳过。
- 重新显示站点后恢复自动签到调度，当天仍未签到的账号会重新检查是否需要补签。
- GitHub 等第三方登录明确要求设备确认、两步验证或人机验证时，暂停该账号的后台重试，避免重复发起无法自动完成的授权。
- 主动重新授权遇到 GitHub 拒绝登录请求时保留前台窗口，供用户处理；短暂请求失败不会被永久当成人工验证。
- 隐藏站点列表会显示“自动签到已暂停”，隐藏与恢复按钮的提示同步说明自动签到状态。

## 需要你手动做的

- 覆盖安装或使用应用内更新，现有账号、凭据、签到记录和定时设置均保留，无需删除账号再添加。
- 以前已隐藏的站点升级后也会暂停自动任务。希望继续自动签到的站点，请在设置中重新显示。
- AgentRouter 的 GitHub 会话需要人工验证时，请点“重新登录”，在前台窗口完成 GitHub 的设备确认或其他验证。授权成功后会解除后台恢复暂停状态；更新关联登录凭据也会允许再次尝试。
- 如果旧版仍在后台运行，先从托盘退出 AutoSign，再安装或启动新版。

## 已知问题

- 本版本不能跳过 GitHub 的设备确认、两步验证、通行密钥或人机验证，也不保证站点网络故障期间的签到成功。
- 自动化回归使用模拟站点；真实 GitHub 登录仍可能因账号安全策略要求用户确认。
- macOS 的应用内更新安装仍受签名条件限制，需要时使用设置页提供的安装包下载入口。
