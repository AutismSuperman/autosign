# AutoSign v0.4.2

发布日期：2026-10-20

## 本次变更

### 修复 macOS 检查更新报「ZIP file not provided」

上一版的 macOS 安装包只有 DMG。应用内更新在 macOS 上依赖 ZIP 包
（系统更新框架只接受 ZIP，DMG 不在它的候选里），找不到就会直接报错，
你在设置页点「检查更新」看到的那串 JSON 就是这个错误。

现在 macOS 会同时产出 ZIP 与 DMG：ZIP 供应用内更新使用，DMG 仍可用于手动安装。

### macOS 更新改为「引导下载安装包」

即使补齐 ZIP，当前 macOS 安装包没有 Apple 开发者证书签名，
系统会用「已安装版本」的签名要求去校验新包，而这类签名一换版本就对不上，
应用内安装必然失败。所以现在 macOS 上：

- 检查到新版本后不再尝试自动下载安装，直接提示「发现新版本」；
- 点「下载安装包」会打开与你电脑架构（Apple 芯片 / Intel）对应的 DMG 直链；
- 覆盖安装即可，账号、站点与登录状态都会保留。

Windows 与 Linux 不受影响，仍然自动下载、退出时安装。

### 更新失败的提示更具体

以前失败时直接显示底层报错（如上面那串 JSON）。现在按原因翻译成一句可操作的话，
并在 macOS 上始终附带「手动下载」按钮，不会出现只能干等的情况。

### 里程碑里会带上本次更新内容

发布说明改为必须随版本提交，缺失会直接让发布流程失败，
不再出现「发布了但不知道改了什么」的版本。

## 需要你手动做的

- **macOS 用户请到 Release 页下载 v0.4.2 的 DMG 覆盖安装一次**。
  这是最后一次需要手动操作：装好这一版之后，今后检查到新版本会直接给出下载链接。
- Windows / Linux 覆盖安装即可，不需要重新配置。

## 已知问题

- macOS 的应用内「一键重启安装」仍然不可用，需要以 Apple 开发者证书签名才能启用。
  在此之前，macOS 的更新方式是「检查到新版本 → 下载 DMG → 覆盖安装」。
- 首次打开从网上下载的 macOS 安装包时，若系统提示来源不明，
  需在「系统设置 → 隐私与安全性」里允许一次。
