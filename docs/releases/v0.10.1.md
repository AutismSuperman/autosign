# AutoSign v0.10.1

发布日期：2026-11-15

## 本次变更

- 修复 GitHub 登录失效后重新授权可能误点通行密钥或其他表单按钮的问题，账号密码和验证码只提交各自所属的表单。
- 修复验证码被页面自动提交后，应用再次点击提交的问题；同一页面的登录表单不会重复提交。
- 改进 GitHub 两步验证方式的识别：使用已保存的 TOTP 时优先选择验证器，不把 TOTP 验证码填入短信验证页面。
- 自动授权遇到 GitHub 的浏览器异常页时及时返回错误，不再停留等待授权超时。

## 需要你手动做的

- 覆盖安装或使用应用内更新，现有账号、凭据和定时设置均保留。
- 对已失效的 GitHub 账号重新发起一次授权；若要求设备确认、人机验证或其他两步验证，请按 GitHub 页面提示完成。

## 已知问题

- 通行密钥、设备确认和人机验证仍可能要求本人操作；本版本不会跳过 GitHub 的安全验证。
- GitHub 的浏览器异常页可能还有其他触发原因；本次修复已通过本地模拟页面回归，尚未覆盖所有真实账号的验证方式。
- macOS 的应用内更新安装仍受签名条件限制，需要时使用设置页提供的安装包下载入口。
