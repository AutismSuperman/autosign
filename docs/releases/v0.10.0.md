# AutoSign v0.10.0

发布日期：2026-11-10

## 本次变更

- 设置中的「关闭窗口」可以选择「后台运行」或「直接退出」。默认延续原来的托盘后台运行，选择会持久保存。
- 移除最小化到托盘、定时签到结束、托盘签到结束和更新下载等系统通知。签到结果仍保留在运行日志，更新结果在设置页显示。
- 移除更新流程的系统对话框。检查更新、已是最新和下载失败直接显示页面状态；主动点击「重启安装」时使用应用内确认框。
- 主窗口和人工授权窗口使用同一套自绘标题栏与窗口按钮，随深浅主题切换；授权窗口显示当前网站来源。第三方登录页面独立运行，不接触应用配置接口。
- 定时执行时间改用应用内输入框，不再弹出系统时间选择器。保留 HH:mm 校验，非法输入不会覆盖原设置。
- 主动退出前等待已排队的配置写入，避免刚修改关闭方式就退出导致设置丢失。

## 需要你手动做的

- 覆盖安装或使用应用内更新，现有账号、凭据、定时设置均保留。
- 想让关闭按钮结束应用，可在「设置 → 界面 → 关闭窗口」选择「直接退出」。
- 使用定时签到时请选择「后台运行」并保持应用运行；直接退出后不会执行后台任务。

## 已知问题

- 第三方登录页面的内容与样式由 GitHub、Linux DO 等网站提供；应用只统一外层窗口，不改写网站的验证页面。
- 托盘右键菜单由操作系统提供，继续使用系统菜单样式。
- macOS 的应用内更新安装仍受签名条件限制，需要时使用设置页提供的安装包下载入口。
