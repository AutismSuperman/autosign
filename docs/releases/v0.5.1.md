# AutoSign v0.5.1

发布日期：2026-10-20

## 本次变更

### 修复 macOS 菜单栏图标过大

macOS 的菜单栏图标只有 22pt 高，而之前托盘直接用了 512px 的彩色应用图标，
系统会把它原样等比塞进菜单栏，结果是一块巨大的蓝紫色方块，
挡住了旁边其他应用的图标。

现在 macOS 使用单独生成的菜单栏图标：透明背景 + 单色图形，
尺寸 22pt，由系统按亮色 / 暗色主题自动反色，和系统自带图标观感一致。

Windows 的托盘图标不受影响。

## 需要你手动做的

- macOS 用户重新安装 v0.5.1 后即生效，不需要改任何设置。
- 其他平台可跳过本版本。

## 已知问题

- macOS 的应用内「一键重启安装」仍不可用，需要 Apple 开发者证书签名才能启用。
  更新方式是「收到通知 → 下载 DMG → 覆盖安装」。
- 首次打开从网上下载的 macOS 安装包时，若系统提示来源不明，
  需在「系统设置 → 隐私与安全性」里允许一次。
